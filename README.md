# Innohub — Creative Agency Website

Innohub is a responsive, modern single-page website for a creative agency built using plain HTML, CSS and a little JavaScript. It showcases a clean layout, services, portfolio/sections, and contact section — suitable as a portfolio or small agency landing page.

![Demo Screenshot](./Screenshot%202024-09-10%20144202.png)

## Demo
- Open `index.html` in your browser to view the site locally.
- For live-reload during development use the VS Code Live Server extension or any local static server (e.g. `npx serve`, `python -m http.server`).

## Features
- Responsive layout with CSS (desktop, tablet, mobile).
- Hero section with call-to-action.
- Services/portfolio sections and contact form UI.
- Small JavaScript for interactivity.

## Technologies
- HTML5
- CSS3 (including responsive techniques)
- JavaScript (vanilla)

## File structure
- `index.html` — main page

## How to run locally
1. Clone the repo:

   git clone https://github.com/BinaryVortex/Innohub-Creative-Agency-Website.git
2. Change into the project directory:

   cd Innohub-Creative-Agency-Website
3. Open `index.html` in your browser, or run a local server:

   npx serve .
   # or
   python -m http.server 8000

## Customization
- Update the content in `index.html` to change sections, text and images.
- Edit `style.css` to adjust colors, spacing, and responsive breakpoints.
- Add new scripts or components in `script.js` for interactivity.
